# مكتبة آفاق — نسخة معاينة تصميمية (GitHub Pages)

## ما هذا بالضبط

نسخة **HTML/CSS/JS ثابتة بالكامل** — لا PHP، لا قاعدة بيانات، لا
ووردبريس. بيانات الكتب مكتوبة يدوياً داخل `data.js` فقط لملء التصميم
بمحتوى واقعي الشكل. الهدف: تطوير القرارات البصرية (ألوان، خطوط،
تخطيط) بسرعة ورؤية النتيجة مباشرة على رابط حي، بلا الحاجة لتشغيل
Docker في كل مرة.

**هذه ليست نسخة من المشروع الحقيقي ولا بديلاً عنه** — هي أداة تطوير
تصميمي منفصلة. أي قرار تصميمي نهائي تعتمده هنا يُنقل يدوياً لاحقاً إلى:
- `wp-content/themes/maktaba-theme/style.css` (الألوان والخطوط)
- `wp-content/themes/maktaba-theme/templates/front-page.php` (تخطيط الصفحة الرئيسية)

## كيف تعمل على GitHub Pages هنا تحديداً

بما أن هذا المجلد (`maktabat-afaq-preview/`) هو مجلد فرعي داخل ريبو
المشروع الكامل (وليس ريبو منفصلاً)، فإن "Deploy from a branch" العادي
في إعدادات Pages **لن يعمل** (بيقرأ من جذر الريبو أو `/docs` فقط، مش
مجلد فرعي عشوائي). لذلك تم إعداد GitHub Action مخصصة:

`.github/workflows/deploy-preview-pages.yml`

**خطوة واحدة تعملها مرة واحدة بس:**
من إعدادات الريبو: **Settings ← Pages ← Source: GitHub Actions** (بدل
"Deploy from a branch"). بعدها أي `push` على `main` يلمس هذا المجلد
سينشر تلقائياً، والرابط هيظهر في نفس صفحة Settings ← Pages، وبرضو في
تبويب Actions بعد كل تشغيل ناجح — عادة بيكون على شكل:
`https://toflog.github.io/maktabat-afaq/`

## طريقة العمل اليومية

أي تعديل على الألوان/الخطوط/التخطيط: عدّل الملفات في هذا المجلد
مباشرة، ثم:
```
git add maktabat-afaq-preview
git commit -m "وصف التعديل"
git push
```
التحديث يظهر على الرابط خلال دقيقة إلى دقيقتين (وقت تشغيل الـ Action) —
بلا Docker، بلا انتظار.

## إضافة كتاب وهمي جديد للمعاينة

افتح `data.js`، أضف عنصراً جديداً لمصفوفة `MKT_BOOKS` بنفس الشكل
الموجود، احفظ وارفع — يظهر فوراً في الصفحة الرئيسية وصفحته الخاصة عبر
`book.html?slug=الاسم-الذي-اخترته`.

## القيود (تذكير)

- لا بحث فعلي، لا سلة فعلية، لا حساب أسعار فعلي (الأرقام هنا مكتوبة
  يدوياً في `data.js`، وليست محسوبة من سعر رسمي + هامش كما في الكود
  الحقيقي)
- زر واتساب يفتح فعلياً لكنه يشير لرقم وهمي (`963000000000`) — غيّره
  في `book.html` إن أردت اختبار الرابط فعلياً
- لا صور أغلفة حقيقية (مربع رمادي "لا صورة" مكانها)
- روابط "تصفح حسب التصنيف" في الصفحة الرئيسية حالياً وهمية (`#`) —
  مقصودة، لأن الفلترة الفعلية جزء من منطق ووردبريس الحقيقي

## تصحيح تم تطبيقه في هذه النسخة

`mktFormatMoney` في `data.js` كانت تستخدم `toLocaleString("ar", ...)`
والذي يفرض أرقاماً هندية شرقية (٣٫٦٠) في متصفحات كروم، بما يتعارض
بصرياً مع رمز `$` اللاتيني ومختصر `ل.س`. تم تغييره إلى `"en-US"`
لعرض أرقام غربية متسقة، بما يطابق ممارسة أغلب متاجر الكتب العربية
التجارية (جرير، نون).
