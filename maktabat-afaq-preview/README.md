# مكتبة آفاق — نسخة معاينة تصميمية (GitHub Pages)

## ما هذا بالضبط

نسخة **HTML/CSS/JS ثابتة بالكامل** — لا PHP، لا قاعدة بيانات، لا
ووردبريس. بيانات الكتب مكتوبة يدوياً داخل `data.js` فقط لملء التصميم
بمحتوى واقعي الشكل. الهدف الوحيد: معاينة القرارات البصرية (ألوان،
خطوط، تخطيط) بسرعة، بلا الحاجة لتشغيل Docker في كل مرة.

**هذه ليست نسخة من المشروع الحقيقي ولا بديلاً عنه** — هي أداة معاينة
منفصلة تماماً. أي قرار تصميمي نهائي تعتمده هنا يجب نقله يدوياً لاحقاً
إلى:
- `wp-content/themes/maktaba-theme/style.css` (الألوان والخطوط)
- `wp-content/themes/maktaba-theme/templates/front-page.php` (تخطيط الصفحة الرئيسية)

## كيف تُشغِّلها على GitHub Pages

1. أنشئ ريبو جديداً منفصلاً على GitHub (مثلاً `maktabat-afaq-preview`)
   — يُفضَّل منفصلاً تماماً عن ريبو الكود الحقيقي (`maktabat-afaq`)
   لتفادي أي لبس بينهما لاحقاً
2. ضع الملفات الأربعة هنا (`index.html`, `book.html`, `style.css`,
   `data.js`) في جذر الريبو مباشرة
3. من إعدادات الريبو: **Settings ← Pages ← Source: Deploy from a
   branch ← Branch: main ← Folder: / (root)** ← Save
4. انتظر دقيقة، سيظهر لك رابط مثل:
   `https://اسم-المستخدم.github.io/maktabat-afaq-preview/`

## طريقة العمل اليومية

أي تعديل على الألوان/الخطوط/التخطيط: عدّل `style.css` مباشرة، ثم:
```
git add .
git commit -m "وصف التعديل"
git push
```
التحديث يظهر على الرابط خلال دقيقة تقريباً — بلا Docker، بلا انتظار.

## إضافة كتاب وهمي جديد للمعاينة

افتح `data.js`، أضف عنصراً جديداً لمصفوفة `MKT_BOOKS` بنفس الشكل
الموجود، احفظ وارفع — يظهر فوراً في الصفحة الرئيسية وصفحته الخاصة عبر
`book.html?slug=الاسم-الذي-اخترته`.

## القيود (تذكير)

- لا بحث فعلي، لا سلة فعلية، لا حساب أسعار فعلي (الأرقام هنا مكتوبة
  يدوياً في `data.js`، وليست محسوبة من سعر رسمي + هامش كما في الكود
  الحقيقي)
- زر واتساب يفتح فعلياً لكنه يشير لرقم وهمي (`963000000000`) — غيّره
  في `book.html` إن أردت اختبار الرابط فعلياً
- لا صور أغلفة حقيقية (مربع رمادي "لا صورة" مكانها)
